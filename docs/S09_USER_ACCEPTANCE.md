# S09 — User Recording Acceptance Checklist

After the real-runtime CI gate is green, the next test is no longer an infrastructure milestone. It is teacher acceptance using user-owned improvisation recordings.

For each MP3/WAV sample, record:

- instrument / texture (guitar, piano, voice, mixed or other);
- approximate tempo/meter if known;
- Basic Pitch note-event count;
- generated ScoreDraft status (`PASS` or `REVIEW_REQUIRED`);
- visibly missing or extra pitches;
- onset/rhythm corrections;
- duration/tie corrections;
- voice assignment corrections;
- measure/meter/pickup corrections;
- Score Editor open/export success;
- optional Guitar TAB usefulness when requested.

Do not convert teacher corrections into hidden automatic authority. Corrections should enter the existing teacher ledger so quality/calibration can be measured by category.

A recording is still useful test evidence when the first draft is imperfect. The acceptance goal is: **usable editable notation with localized uncertainty**, not zero teacher edits.
